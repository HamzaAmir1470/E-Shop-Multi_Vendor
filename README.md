# 🛒 E-Shop Multi Vendor Marketplace

A full-stack **Multi Vendor E-Commerce Marketplace** built with the **MERN Stack**.
This platform allows multiple vendors to manage their own stores, products, orders, and customers through dedicated dashboards while customers enjoy a modern online shopping experience.

Built with scalability, authentication, responsive UI, and secure APIs in mind.

---

## 🚀 Live Demo

🔗 **Live Preview:** *https://sultanf.vercel.app/*

---

## 📌 Project Overview

E-Shop Multi Vendor is a modern marketplace platform inspired by real-world applications like Amazon and Daraz. The application supports:

* Multi-vendor store management
* Secure authentication & authorization
* Product and inventory management
* Cart & checkout system
* Order management
* Admin controls
* User-specific dashboards
* JWT authentication
* Image uploads
* Responsive UI

This project was developed to strengthen full-stack development skills using industry-standard technologies and architecture.

# 🧪 Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/HamzaAmir1470/E-Shop-Multi_Vendor.git
```

---

## 2️⃣ Navigate to Project Directory

```bash
cd E-Shop-Multi_Vendor
```

---

# 📦 Backend Setup

## Install Dependencies

```bash
cd backend
npm install
```

## Create `.env` File

```env
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
CLIENT_URL=http://localhost:3000
```

## Run Backend Server

```bash
npm run dev
```

---

# 💻 Frontend Setup

## Install Dependencies

```bash
cd frontend
npm install
```

## Start Frontend

```bash
npm start
```
